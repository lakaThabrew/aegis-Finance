# Testing Guide

This guide explains how to test the Aegis microservices and the Flutter frontend.

## 1. Backend Microservices API Testing (cURL / Postman)

### Step 1: Start the Backend Services
**Automated Method**: Double-click `start-backend.bat` in the project root to start all 5 services simultaneously.
**Manual Method**: Refer to the manual startup steps in the README to start services individually.

### Step 2: Obtain a JWT Token from Keycloak
Before testing the Core Banking APIs, you must authenticate as a user .

```bash
curl -X POST http://127.0.0.1:8080/realms/aegis/protocol/openid-connect/token \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "grant_type=password" \
  -d "client_id=aegis-frontend" \
  -d "username=you@aegis.finance" \
  -d "password=password123"
```
*Copy the `access_token` from the JSON response. You will use this in the `Authorization` header for subsequent requests.*

### Step 2: Test Core Banking Accounts API
Fetch the accounts for the authenticated user:
```bash
curl -X GET http://127.0.0.1:8081/api/v1/core/accounts \
  -H "Authorization: Bearer <YOUR_ACCESS_TOKEN>"
```

### Step 3: Test Card Management API
Fetch the user's cards:
```bash
curl -X GET http://127.0.0.1:8081/api/v1/core/cards \
  -H "Authorization: Bearer <YOUR_ACCESS_TOKEN>"
```
*Copy the `id` of the card from the response.*

Update card security controls (e.g., Freeze the card):
```bash
curl -X PATCH http://127.0.0.1:8081/api/v1/core/cards/<CARD_ID>/controls \
  -H "Authorization: Bearer <YOUR_ACCESS_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{"isFrozen": true, "contactless": false}'
```

## 2. Testing the Mobile Application

### Running the App
1. Make sure all backend services are running.
2. In the `apps/aegis_mobile` directory, run:
   ```bash
   flutter run
   ```

### UI Testing Workflows
- **Login Flow**: Verify that entering the correct credentials navigates to the Dashboard, and invalid credentials show an error.
- **Transfers**: 
  1. Navigate to Quick Actions -> Transfer.
  2. Select an account, enter a valid receiving account (e.g. `AGS-0077-2024`), enter an amount, and submit.
  3. Verify the Dashboard total balance decreases by the transferred amount.
- **Card Security**: 
  1. Navigate to Quick Actions -> Cards.
  2. Toggle the "Freeze Card" switch.
  3. Navigate back to the Dashboard, then re-open the Cards screen. 
  4. The switch should remain in the toggled state, confirming that the database was successfully updated via the API.
- **Aegis AI Assistant**: 
  1. Open the AI Assistant from the top right of the Dashboard.
  2. Ask "What is my balance?" and ensure the AI accurately responds with the balance displayed on your Dashboard.
  3. Ask "Transfer $10 to AGS-0077-2024" and verify that the AI successfully initiates and processes the transaction workflow.

## 3. Testing the Web Applications

### Starting the Web Apps
**Automated Method:**
1. Double-click the `start-frontend.bat` script in the root directory to instantly start both Customer and Admin web apps.

**Manual Method (Customer Web App):**
1. Navigate to `apps/customer-web`
2. Run `npm install` and then `npm run dev`

### Testing the Customer Web App
1. Open `http://localhost:5173` (or the port specified in terminal)
2. Log in using a demo account (`customer-001`).
3. Ensure the dashboard accurately reflects the user's data by cross-referencing with the Core Banking API.
